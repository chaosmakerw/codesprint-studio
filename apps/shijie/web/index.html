使用说明与备份

    

      
准备工作，交给你的 Agent
首次运行：电脑需有 Python 3.12 或更高版本。解压后双击 START.cmd。Agent 可从 本机接入协议 读取提示词与接口说明。应用本身不会自动登录或连接你的 Agent。
将项目和学习资料准备在电脑上，把下面提示词交给自己的 Agent。它会读取软件内置协议，整理项目总结、功能方法链、参数示例和复习题，通过本机接口校验并写入。以后打开拾阶即可独立学习。
查看交给 Agent 的完整要求

      
导入完整学习包
学习包先用功能场景和调用链说明项目，再提供步骤知识、参数示例、练习、答案和来源。不限语言，无需先让扫描器识别项目。

      
导入一个本机项目快照
只读取允许的源码和说明文件，自动跳过构建目录、配置密钥与二进制文件。快照用于保留来源，仍需 Agent 整理成完整学习包。
或者

      
补充当前项目的学习资料
可上传自己的 Markdown 或文本笔记，再导出接手文件交给 Agent。资料更新会增加项目版本，保留历史记录；需要按新版本重新生成知识与题目。

      
把学习记录保存下来
备份包含项目快照、练习答案和提示记录。文件只由你保存，不会自动传到云端。

      
移除当前项目快照
只移除这个应用保存的快照与相关练习记录。原项目文件不受影响。建议先备份。
