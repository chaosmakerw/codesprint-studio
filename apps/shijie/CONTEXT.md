# 拾阶的学习语言

拾阶帮助学习者从具体实例提炼知识，通过理解、解释、练习与复核形成自己的能力。当前先支持从用户自己的软件项目进入这条过程。

## Language

**学习实例**：学习者准备的一份具体对象，是理解和验证知识的起点。当前实例是软件项目，以后可以扩展为书籍或其他案例。
_Avoid_：固定课程、默认校园项目

**来源**：用于支撑讲解和判断的项目内容、学习资料或明确记录出处的补充材料。来源存在不代表其说法已经验证正确。
_Avoid_：自动可信答案

**功能场景**：一次具体使用行为，先说明使用者想做什么、给了什么输入、预期得到什么结果。
_Avoid_：从类名目录开始学习

**场景调用链**：围绕功能场景整理的有序执行讲解。每一步说明谁负责、接收什么、做什么、返回什么、为何这样设计，并关联知识和源码依据。
_Avoid_：裸方法列表、自动生成的真实调用图

**参数与资源追踪**：在已经理解的调用链中，用具体输入逐步观察变量类型、值、来源以及资源归属和生命周期。当前追踪是依据源码整理的教学推演，运行证据另行记录。
_Avoid_：实时调试器、真实执行日志

**知识点**：从实例中提炼的一个可理解、可解释、可实践的原理，具有讲解、前置关系与来源依据。
_Avoid_：框架名称清单

**学习包**：使用者自己的 Agent 根据来源整理的项目总览、功能调用链、知识点与题目集合，在授权范围内通过预览校验后进入拾阶。用户授权自动准备时由Agent完成提交。
_Avoid_：可执行插件、模型账号接入

**练习**：学习者针对一个知识点进行的预测、跟踪、排错、复现或迁移活动，保留第一次回答与实际帮助程度。
_Avoid_：看过讲解即完成

**客观检测**：具有固定答案的题目组成的一次检测，结果反映本次题目上的正确率。达到通过线不等于独立掌握整个知识领域。
_Avoid_：能力认证

**能力证据**：学习者的原始回答、使用的帮助、实际操作、测试或延迟复测记录。不同来源和验证范围的证据分别保留。
_Avoid_：自动掌握百分比

**复核**：使用者、教师或其 Agent 结合来源审阅开放回答与操作证据的过程，仍需区分参考意见和实际验证。
_Avoid_：关键词命中率

## 四阶段

**项目总览**先说项目有什么用、谁使用、输入得到什么、有哪些实际功能及学习价值；内容缺失保持可见，不靠文件数量或技术标签冒充总结。

**功能与调用链**先按功能读一条人话顺序，再看每个实际方法的调用、返回与停止。具体案例在软件内逐帧显示值与资源变化，源码只是折叠依据；遗漏的帧表示尚未记录，只有明确分支证明未调用。

**周期总结**由使用者每隔n天用自己的话重述项目目的、正常与失败链、设计取舍和未知处。保存原始自述，反馈需要依据，不把关键词转换成虚假的理解分数。

**知识复习**用从项目提炼的知识和原创选择题反复回忆，保留首答、错题、到期复习与随机检测。80%是本轮客观题门槛，不是整个项目的掌握百分比。

部署、项目上传、材料整理与导入是一次准备工作，放在说明与本机Agent协议。拾阶本身不提供模型账号或远程Agent连接，外部准备能力来自使用者自己的Agent。
