# 原创 Python 示例：笔记任务队列

这是一个用于学习的短实例，不要求你重写自己的项目。它展示任意语言项目都能导入自定义知识、讲义和检测题；与 Java 示例互相独立。

让自己的Agent按 `prompts/first-run.md` 和本机API说明预览并导入本目录的 `learning-bundle.json`；用户已授权自动准备时由Agent完成提交。包内包含两份源码、四份原创教材、4 个知识点（3 组）、15 道客观题与 4 道保留的开放练习。客观多选包含2、3、4个正确项，答案来自机制，不硬凑数量。

导入后按“项目总览 → 功能与调用链 → 周期总结 → 知识复习”学习。先明白项目用途，再进入“任务入队”或“取出并再次入队”，软件内已经列出每个实际方法和具体输入的逐步追踪。由学习者每隔设定天数重述项目目的、正常与非法路径及设计取舍；刷题按实际知识回忆，本次5题正确4题是80%，分母是这一轮题数，首答与受助程度单独记录。检测通过不自动证明独立复现。去重仅覆盖待处理状态，取出不等于业务处理成功；流程是源码手算预测，与实际测试分开。

源码与教材均为本仓库原创，不联网、不使用真实私人数据。程序只在单线程内存中工作，无数据库、HTTP、模型或持久化。应用只读取源码，不执行示例；下列命令用于开发者自己验证原创实例：

```text
python -m unittest discover -s project -v
python generate_bundle.py
```

`generate_bundle.py` 只读取本目录固定的原创文本并生成包；它不导入或执行 `job_queue.py`。修改教材或源码后重新生成包，引用的行号与 UTF-8 SHA256 会同步更新。知识、练习及行锚点均在生成器中维护，生成时锚点丢失会直接失败。
