# 本人订单教学示例

这是为拾阶另写的最小 Java 17 示例，不是完整 Spring 应用，不连接数据库或模型。用它练习 Map、接口、构造器注入、record、Long 的值比较、提前返回和异常边界。

模型可以提供工具名和参数，身份由 CurrentUserContext 提供。list_my_orders 不接受参数；校验成功后，OrderTools 只向服务传递当前身份。管理员身份也不会自动改变该工具的数据范围。

FakeOrderService 保存两条固定订单，买家分别为 1001 和 1002。Fake 表示教学替身，不能据此声称持久化、真实认证或生产权限已验收。

ConversationMemory 故意采用普通 HashMap 并返回可变列表，供学生分析引用泄漏和并发边界。它不应被当作生产会话存储。

在拾阶的准备说明中点击“体验Java示例”，或让自己的Agent按本机协议预览并导入本目录的 `learning-bundle.json`。然后按“项目总览 → 功能与调用链 → 周期总结 → 知识复习”学习：先明白用途，再看本人订单或会话消息功能的方法进入与返回，用成功、伪造字段、未登录和失败依赖追踪具体值。包内有 6 个知识讲义、16 道客观题和 4 道保留的开放练习；客观多选包含2、3、4个正确项，并留有干扰项。

周期总结由学习者每隔设定的天数用自己的话写项目理解，不自动精确评分。刷题保留首答、错题、到期复习与80%本轮检测门槛。流程是源码教学推演；答对不证明已独立复现，更不证明真实模型、HTTP或生产权限。

`generate_bundle.py` 只读取本目录固定的原创 Java、README 与 pom 文本并重新生成学习包，引用行号与 UTF-8 SHA256 同步更新；它不运行 Java。学习链的明确前提是调用者手动组合 Dispatcher、Validator、OrderTools、可信身份上下文与 Fake。示例没有 main、HTTP 入口、真实身份实现、框架装配、Converter 或数据库 Connection，不能把这些能力视为已有。
