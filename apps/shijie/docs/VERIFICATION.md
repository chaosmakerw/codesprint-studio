
## 发布时核对

1. 暂存区与 Git 历史审计通过，提交作者使用公开账号及 GitHub noreply 邮箱；不混入未授权的工作区根目录修改。
2. 公共种子只从两个原创例子生成，原题、解析、引用和源码哈希可核对；私用安装包留在本机。
3. 模拟器或真实设备用隔离数据完成首次启动、复习、导出、恢复与重开；测试不写入用户学习库。
4. 发布资产名称、版本、SHA256 与实际附件一致；最新本地或 CI 结果能追溯到发布代码。

本文件记录范围与复验方法，不沿用个人学习站的测试数量来声称当前公开 APK 已完成验收。具体执行结果见对应版本的 GitHub Actions 与 Release 说明。
