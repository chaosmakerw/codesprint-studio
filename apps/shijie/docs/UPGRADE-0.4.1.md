# 拾阶 0.4.1

## 打开应用

解压后双击 `START.cmd`。需要 Python 3.12 或更高版本；运行时只使用 Python 标准库，不需要安装 Node.js 或第三方服务。

首次启动会打开本机应用。启动窗口提供本机服务，学习时保留该窗口；关闭服务后，浏览器里的旧地址不能自行启动应用。再次双击同一份应用的 `START.cmd` 会重新打开正在运行的服务。

默认地址是 `http://127.0.0.1:8769`。如果该端口由其他应用、其他数据目录或旧版拾阶使用，启动器会说明冲突并提供另一端口的命令；它不会关闭其他程序。网页提示无法连接时，先启动应用，再点击“重新连接”。

## 本版行为

- 日常复习优先覆盖不同知识点，轮换薄弱或到期题与未见题，并兼顾追踪、诊断、迁移等题目角度。
- 知识筛选显示实际客观题数，题目上方标明对应知识和练习角度。
- 未完成的验收测验可以从历史继续，保留当次题目和选项顺序；尚未提交的选择需要重新选择。日常复习已提交的首答继续保存。
- 小屏幕上标题与通过线标记分开排列，主要学习按钮保留足够的触控高度。
- Agent 可以通过 `concept_updates` 给已有知识追加讲义、机制、故障和来源。它不能删改原文、知识身份、前置关系、源码证据或旧题；预览后原文已变化时整包拒绝。

## 学习内容与本机数据

四阶段仍是“看懂项目 → 拆解功能 → 我的理解 → 复习验收”。来源引用、方法链与参数追踪支撑学习；客观题达到 80% 只代表本次检测通过，不能代替独立解释和复现。

分发 ZIP 仅包含应用、准备协议与合法示例，不包含个人项目快照、作答、浏览器配置或本机密钥。个人学习数据在应用的 `data` 目录；升级和导入前先通过 `/api/backup` 备份，不要删除该目录。已有内容的补充使用当前 handoff 的版本与源码哈希，先预览再提交，保留原有记录。

此版不会自动运行被学习的项目、访问真实模型或替使用者填写学习总结。
