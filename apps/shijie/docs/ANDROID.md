# 拾阶安卓离线版

拾阶是独立应用，包名 `io.shijie.learning`，不会覆盖拾知。适用于 Android 8.0 及以上，公开版安装包见 [Releases](https://github.com/chaosmakerw/codesprint-studio/releases/tag/shijie-v0.4.1)。

## 安装与学习

1. 下载 `shijie-0.4.1-sample.apk`，在手机文件管理器中打开安装；按系统提示允许该文件管理器安装应用。
2. 打开拾阶，从项目选择框切换两个原创示例。按“看懂项目 → 拆解功能 → 我的理解 → 复习验收”学习。
3. 日常复习逐题查看解析，验收模式整组核对。答题后即可保存；中断的复习从“历次检测记录”继续。
4. 卸载、清除数据或换设备之前，在“使用说明”导出完整备份。使用系统文件选择器确定位置，收到保存成功提示后再操作。

首次打开带有两个原创项目、31 道客观题。项目内容、讲义、页面与答题都可离线使用；外部资料链接只有主动点击时才交给手机浏览器。

## 学习自己的项目

手机自身不运行 Agent，也不读取电脑目录。在“使用说明”复制首次准备提示词，交给电脑上的 Agent，并提供项目与学习资料。

Agent 按 [数据协议](../prompts/reference.md) 生成完整学习包 JSON。把文件传到手机，在“使用说明 → 导入完整学习包”选择文件，检查项目总结、方法链、参数追踪、知识与题目，确认后导入。该操作新增一个项目。

已有项目可在“补充题目与交给 Agent”导出接手文件，生成绑定版本和来源哈希的补充任务包，再预览确认。过期包、覆盖既有题目和删改受保护讲义会拒绝。

电脑与手机也可以互相恢复完整备份。**恢复会替换目标设备的全部学习数据**，不是自动合并；先备份目标设备需要保留的记录。两端没有自动同步。

## 保存与隐私

记录存于应用自己的 IndexedDB，安装包升级不会主动替换已有数据库。卸载或清除应用数据会删除记录，系统备份已关闭，需要自己导出。

正式版不申请网络、广泛文件访问、相机、麦克风或定位权限；没有账户、遥测或自动上传。导入导出只使用用户选择的系统文档 URI。备份是可读 JSON，包含导入源码与自己的回答；分享前自己核对。

公开安装包只带仓库原创示例与空学习记录。个人题库、项目快照、电脑路径、密钥、签名私钥、个人安装包和私人截图不进入仓库或 Release。

## 从源码构建

本构建脚本当前使用 Windows 官方 Android SDK 工具，需 JDK、`android-36` 与 `build-tools 36.0.0`。

```text
python scripts/build_mobile_seed.py
python android/build.py --sdk <Android-SDK目录>
```

输出为 `android/dist/shijie-0.4.1-sample.apk`，默认只读取原创 `examples/mobile-seed.json`，不读取桌面 `data/`。私用构建必须显式提供 `--flavor personal --seed <私用备份JSON>`，不要公开该产物。

第一次构建生成通用应用签名，保存在 Git 忽略的 `android/private-signing/`。请安全保存整套签名身份，后续升级需使用相同签名。自建签名与官方发布签名不同，无法直接覆盖官方安装包；更换之前先导出备份。

构建校验签名、对齐、权限、资产哈希和私钥排除。实际设备验证方法见 [验证范围](VERIFICATION.md)；模拟器通过不代表所有品牌手机均已实测。
