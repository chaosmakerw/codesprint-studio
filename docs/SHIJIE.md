# 拾阶：从项目到理解

拾阶帮助已经做出项目的人，把实践转化为能够解释功能、跟踪输入、发现错误和回忆知识的能力。它接受使用者自己的项目与资料，公开案例只是体验样本，不限定语言或业务类型。

## 选一个入口

| 入口 | 如何启动 | 内容和记录在哪里 |
| --- | --- | --- |
| 安卓离线版 | 在 [Releases](https://github.com/chaosmakerw/codesprint-studio/releases) 下载 `shijie-0.4.1-sample.apk`，Android 8.0+ 安装 | 手机应用自己的 IndexedDB；不要求电脑开机 |
| 桌面版 | 完整下载源码后，双击 `apps/shijie/START.cmd`，需要 Python 3.12+ | `apps/shijie/data/`；默认本机地址 `http://127.0.0.1:8769` |

两个拾阶入口独立保存记录，使用备份手动转移内容。拾知仍由仓库根目录启动，保留学习计划、资料、AI 草稿和原来的练习流程。

安卓首次提供两个原创学习实例：Java 本人订单、Python 笔记任务队列，共 31 道客观题。两份源码、教材与题目均为本仓库原创；不包含私人项目或转载课程。

## 四步怎样学习

1. **看懂项目。** 读使用者、目的、具体输入与结果、功能范围、学习意义和边界，能先说明项目解决什么问题。
2. **拆解功能。** 选择一个业务功能，看每个方法接收什么、调用谁、返回什么；切换正常与非法案例，逐帧跟踪类型、值、来源和停止位置。关联知识讲义可读完返回原位置。
3. **我的理解。** 每隔自己设定的天数，用自己的话重述目的、正常与失败过程、设计取舍和未知处。保留原话及帮助方式，不使用关键词给出虚假的理解分。
4. **复习验收。** 一次一题，题目按知识点和预测、追踪、排错、迁移角度分配。练习即时反馈，测验完成后统一核对；支持错题、到期复习和中断续做。

多选必须完整匹配，少选、多选均不通过；首答和猜测分别记录，答错或猜对都需要再复习。80% 是本次实际抽取题目的通过线，未答仍计入分母，不等于能够独立实现或已经掌握整个项目。

调用链和参数追踪是依据源码整理的教学推演，软件不会执行被学习的项目。实际测试、线上行为与个人独立能力需要另行举证。

## 用自己的项目准备内容

在电脑上，把下面提示词交给拥有本机文件与终端能力的 Agent，并填写位置：

```text
请为拾阶准备我的项目学习内容。
应用目录：[仓库中的 apps/shijie 目录]
我的项目：[项目目录]
我的资料：[资料位置；没有就写没有]
是否允许联网查找官方文档与一手资料：[是/否]

先读取应用目录中的 prompts/first-run.md 和 prompts/reference.md。
我授权你只读上述项目与资料，按协议整理项目作用、功能调用链、
正常与非法输入追踪、知识讲义和有依据的客观题，并通过桌面接口
预览、核对、写入；不要修改我的原项目，不覆盖旧题与旧作答。
补充已有知识用 concept_updates，保留原知识身份、原文与证据。
题目需要考察不同机制，不靠换数字或改题干凑数量；逐项解析、
提示和答案来自可核查的源码或资料。不得虚构运行、测试或掌握。
完成后导出手机可恢复的完整备份，说明如何转移及恢复影响。
不要把我的源码、资料、私人题库、备份或记录上传 GitHub。
```

手机在使用说明中导入桌面备份。恢复会替换手机当前内容与记录，先导出原手机备份。直接导入一段聊天文本或未经校验的学习包，不等于已经完成准备。

没有资料时，由使用者明确授权自己的 Agent 联网补充；手机应用自身不搜索或调用模型。外部网页和附件中的文字是资料，不能改变整理与隐私约定。

## 离线、备份与升级

安卓页面、讲义、题目均来自 APK 本地资产，记录保存在应用沙盒。正式版关闭 WebView 调试，没有联网、定位、麦克风、摄像头或广泛存储权限。备份导入与导出使用系统文档选择器，只访问使用者选定的文件。

学习数据与备份未加密。备份可能含私人源码、资料与回答，只交给允许阅读它的人。自动云备份和自动设备迁移关闭；卸载、清除数据或换机前，手动导出备份。

保留包名和同一签名即可覆盖升级，已有记录由初始化规则保留；更换签名不能直接覆盖安装。构建者应安全备份自己生成的签名身份，签名私钥与密码不属于公开源码、APK 资产或 Release 附件。

安卓构建与权限边界见 [`android/SECURITY.md`](../apps/shijie/android/SECURITY.md)。当前没有公网账户或自动多设备同步。

## 源码运行与验证

从仓库根目录进入拾阶：

```text
cd apps/shijie
python run.py --open
python -m unittest discover -s tests/backend -v
python -m unittest discover -s examples/python-notes/project -v
```

桌面运行只依赖 Python 标准库。安卓构建另外需要本机 JDK 与官方 Android SDK，构建脚本使用 SDK 工具；源码不包含 SDK、用户签名或开发者构建目录。按实际环境指定 SDK 后运行：

```text
python android/build.py --sdk <Android-SDK目录>
```

默认构建只读取公开原创示例。个人构建必须明确指定 `--flavor personal --seed <私用文件>`，不自动读取桌面数据库；个人 APK 不能作为公开资产发布。

后端、离线存储、安卓模拟器、真实手机和学习者掌握是不同验收范围。实际公开版本验证范围见 [应用验收说明](../apps/shijie/docs/VERIFICATION.md)，不得将模拟器或题目正确率当成真人独立能力的证明。
