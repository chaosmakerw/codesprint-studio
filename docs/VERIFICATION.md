## 测试证明什么

后端使用真实临时 SQLite、原始资料文件和回环 HTTP 服务；AI 是明确的受控 Stub，不是 Mock 数据库。测试不启动 Spring，不访问个人学习数据库，不调用真实模型。

验证了上传、搜索、收藏和回收站、来源绑定、结构 / 逐字证据校验、草稿与写入分离、重试幂等、并发提交只写一次、来源失效不写库，以及整包备份恢复。恢复测试修改备份后段的答案、题目版本和草稿，确认全量校验失败时不覆盖现有库。

原有练习规则覆盖成功和拒绝两侧：单多选精确判分、16 / 20 达到 80%、15 / 20 不通过、未答计入固定分母、首答锁定、顺序约束、猜对复习、到期与提前答对边界、资料失效时历史保留但复习暂停。随机显示选项的解析按当前选项文本和顺序生成，避免 A/B/C/D 错位。

供应商安全检查通过注入的网络替身验证：拒绝非 HTTPS、内网和含用户信息的地址，不跟随重定向，不把上游错误正文和密钥返回网页；并验证异常释放生成并发许可。替身验证不能证明任意真实供应商兼容或模型必然遵守提示词。

## 浏览器与外观

Edge 使用隔离配置与临时资料目录，真实上传文件、下载原件和 ZIP、恢复记录。停止临时 HTTP 服务后在同一数据目录重新启动，首答和未完轮保持。AI 工坊使用 FixtureProvider 完整走过生成、展示证据、人工确认、写入及随后练习。

四主题持久保存并在 320 / 390 / 412 像素和桌面宽度检查资料及练习，未出现页面横向溢出；上传的 HTML / 脚本只作文本展示，没有执行。原件下载字节与上传一致。

项目自身外部资源请求和页面脚本异常为 0。本机安全软件向浏览器注入的独立脚本在隔离测试中阻断并单独统计，不修改系统安全软件，不把环境注入算作项目素材，也不忽略其它外部请求。

README 的五张截图来自实际浏览器、原创示例和应用视口，不包含桌面、个人账户、地址栏或本机路径。截图不是静态设计稿，也不是用户实体手机实测。

## 当前局限

- 尚未使用真实 API Key 实测付费模型，模型兼容性、真实题目质量、费用和供应商数据政策需要使用者核对。
- 结构与原文引用检查不能判断所有语义错误、引用是否真的支持答案或是否涉及第三方权利；写库前仍需人审。
- 这是本机工具，尚未验证公网多用户、多人权限、生产部署、大规模并发或高可用。
- PDF 可以存放和下载，未实现 OCR 或 PDF 正文自动提取。AI 出题使用有权处理的可读文本。
- 运行数据和备份默认不加密；只向公开仓库发布源码、原创示例及截图，个人资料不随仓库上传。

任何后续修改都应重新验证受影响的行为，并据实际结果更新说明；不要把本轮替身模型测试或浏览器模拟宽度扩大解释成真实模型或实体手机验收。
